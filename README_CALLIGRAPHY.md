# Chinese Calligraphy Art - 2026 马到成功

This script generates beautiful, colorful calligraphy artwork of "2026 马到成功" (2026 - Immediate Success).

## Features

- ✨ Colorful rainbow gradient effects on text
- 🎨 Multiple layered text with different colors for depth
- 💫 Glow and shadow effects
- 🎯 Decorative circular elements
- 🖼️ High-quality PNG output (300 DPI)

## Requirements

- Python 3.7+
- matplotlib
- numpy
- pillow
- Chinese fonts (WenQuanYi Zen Hei, Noto Sans CJK, or similar)

## Installation

```bash
# Install Python dependencies
pip install -r requirements.txt

# Install Chinese fonts (Linux/Ubuntu)
sudo apt-get install fonts-wqy-zenhei fonts-noto-cjk
```

## Usage

```bash
# Run the script
python calligraphy_2026.py
```

The script will generate a file named `calligraphy_2026_马到成功.png` in the current directory.

## Output

The generated artwork features:
- Text: "2026  马到成功"
- Size: ~4770 x 2955 pixels
- Format: PNG with transparent/gradient background
- Style: Modern calligraphy with vibrant colors

## Meaning

"马到成功" (mǎ dào chéng gōng) is a Chinese idiom that literally means "success comes when the horse arrives." It's commonly used as a blessing for immediate success and is particularly appropriate for 2026, which is the Year of the Horse in the Chinese zodiac.
